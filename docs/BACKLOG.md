## 1. Требует внимания

### 1.1 OpenRouter-прокси не поставлен — генерация на локальном fallback

Cloudflare OpenRouter'а отдаёт `403 Access denied by security policy` на IP прод-сервера
(89.169.163.73, Yandex Cloud RU) **с 13 июля 2026**. Это блокировка по гео/IP, не по ключу.

Проверено 2026-08-21: за сутки **18 генераций** ушли через
`bot/services/prompt_fallback.py` — то есть промпты собираются локально из словарей,
а не пишутся GPT-5.2. Бот работает, но качество промптов ниже задуманного.

- **Блокер:** нужен рабочий прокси (`http://user:pass@host:port` или `socks5://host:port`).
- **Как чинить:** прописать `OPENROUTER_PROXY` в `/opt/photoshoot_ai/.env`, перезапустить сервис.
- **Как убедиться:** `sudo journalctl -u photoshoot_ai | grep 'Using LOCAL fallback'` —
  после починки WARNING перестаёт появляться.

### 1.2 Блог встал: темы кончились

Все 50 тем в `blog/topics.json` помечены `done`. Крон трижды в день (08:00 / 14:00 / 20:00 МСК)
пишет в `/opt/photoshoot_ai/blog/autogen.log`: `All topics exhausted! Add more to topics.json.`
На сайте 52 статьи, новых не появится.

**Важно:** долить темы недостаточно. `blog/autogen.py` ходит в тот же заблокированный
OpenRouter и фолбэка не имеет — упадёт, пока не решён пункт 1.1. Порядок: сначала прокси,
потом темы.

### 1.3 Telegram DNS — костыль вместо решения

Прод держится на прибитом IP в `/etc/hosts` (`149.154.167.220 api.telegram.org`, с 4 июня).
Если Telegram сменит адрес, бот молча замолчит — симптом уже был: сервис `active`,
апдейты не приходят, `tryings` растёт.

Кандидаты на нормальное решение (нужен брейншторм, не выбрано):
кастомный резолвер в сессии aiogram, ограниченный живой подсетью `149.154.167.0/24`,
либо SOCKS5/HTTP-прокси через `AiohttpSession(proxy=...)`.

### 2.1 Чеки НПД — работают, не проверен путь отказа

Проверено на живом проде 2026-08-21: `NPD_ENABLED=true`, модули `npd_*.py` на месте,
20 августа в 18:42 сквозь бота прошёл **реальный чек** — платёж 17 на 349 ₽,
чек `2004cec42j`, строка в `npd_receipts` в статусе `sent`, `attempts=0`.

Осталась одна ступень: **путь отказа** — сломать пароль → убедиться, что после
исчерпания ретраев приходит алерт админу и `/receipts_retry` добивает чек.

Не забыть: аннулировать тестовый чек на 10 ₽ из `scripts/npd_check.py income`, если ещё нет.
